# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-02

Titles and abstracts arrive as plain text, HEPData record links open the record they describe, citation exports page past 50 entries, and citation summaries add citations per year.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-10-01

First published release — eight read-only tools and one resource over INSPIRE-HEP: literature search, paper records, BibTeX and LaTeX export, author profiles, citation summaries, experiments, and HEPData record lookup.

## [0.1.0](changelog/0.1.x/0.1.0.md) — 2026-09-29

Unpublished project scaffold from @cyanheads/mcp-ts-core — no package was released under this version.
