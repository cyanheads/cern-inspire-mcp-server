# 0.1.2 — 2026-10-02

## Added

- **`page` on `cern_inspire_export_citations`** — exports sets larger than one `size`, up to the first 10,000 matches (`beyond_result_window` past that); output gains `page` and enrichment gains `nextPage`. A later page adds one parallel match-total request. ([#8](https://github.com/cyanheads/cern-inspire-mcp-server/issues/8))
- **`citationsByYear` on `cern_inspire_get_citation_summary`** — citations received per year, from a parallel `citations-by-year` facet request (at most 2 in flight). Omitted with a notice under `year_from`, `year_to`, or `exclude_self_citations`, when INSPIRE does not return it, and past about 150,000 matched records unless INSPIRE answers within 2 s. ([#10](https://github.com/cyanheads/cern-inspire-mcp-server/issues/10))
- **`hepdata.otherRecords` on `cern_inspire_get_paper`** — a paper's other HEPData records, in ascending record number; the availability lookup reads up to 10, and a notice names them. ([#6](https://github.com/cyanheads/cern-inspire-mcp-server/issues/6))
- **Affiliation queries** — `cern_inspire_list_reference` documents `aff NAME`, `affid:N`, and the institution recid; `institutionRecid`, `institutions[].recid`, and the citation-summary `query` point at `affid:N`. ([#9](https://github.com/cyanheads/cern-inspire-mcp-server/issues/9))
- **Public hosted endpoint** — `https://cern-inspire.caseyjhand.com/mcp` (Streamable HTTP), listed in the README and in `server.json` `remotes`.

## Changed

- **Bare-words hint in `cern_inspire_search_literature`** — INSPIRE's affiliation operators (`aff`, `af`, `affil`, `affiliation`, `inst`, `institution`) and hyphenated fields such as `affiliation-id:` count as field operators. ([#9](https://github.com/cyanheads/cern-inspire-mcp-server/issues/9))
- **`upstream_unreadable` recovery** on `cern_inspire_export_citations`, `cern_inspire_search_literature`, and `cern_inspire_search_hepdata` — says to wait a minute and retry with the same page and size, not a smaller size, which would shift a paged caller's results.

## Fixed

- **Titles and abstracts as text** — publisher HTML, JATS, MathML, and entities in INSPIRE and HEPData titles and abstracts convert to plain text (`markupToText()`) in `structuredContent` and `content[]`; LaTeX stays as published and export entries stay verbatim. Rendered text escapes `*`, `~`, and `_` outside a word. ([#7](https://github.com/cyanheads/cern-inspire-mcp-server/issues/7))
- **`hepdataUrl`** is `https://www.hepdata.net/record/<N>` from the HEPData record DOI (`/record/ins<recid>` only when the DOI names no number), so it opens the record whose DOI and table count it reports. ([#6](https://github.com/cyanheads/cern-inspire-mcp-server/issues/6))
- **Merged recids** — `cern_inspire_get_paper` and `inspire://literature/{recid}` follow INSPIRE's redirect to the surviving record instead of failing `paper_not_found`, with the new `mergedFrom` field and a notice. ([#13](https://github.com/cyanheads/cern-inspire-mcp-server/issues/13))
- **`paper` input schema** — advertises no `pattern` (checked in a refinement), so schema-validating clients accept the documented prefixed and URL spellings; facet descriptions document only the enum array. A HEPData record URL or DOI passed as `paper` gets the `cern_inspire_search_hepdata` route to its paper. ([#11](https://github.com/cyanheads/cern-inspire-mcp-server/issues/11))
- **`hepdataRecid` label** — `cern_inspire_search_hepdata` text prints it as the HEPData record number, not a recid, and its description routes `cern_inspire_get_paper` to `paperRecids`. ([#11](https://github.com/cyanheads/cern-inspire-mcp-server/issues/11))
- **Placeholders and echoes** — notices and recovery hints spell placeholders as uppercase words (`"t WORDS"`, `"a NAME"`), never `<…>`; caller echoes (`callerEcho()`) and identifier values (`identifier()`) print as written, with `<` neutralized only where it could open markup. ([#12](https://github.com/cyanheads/cern-inspire-mcp-server/issues/12))
