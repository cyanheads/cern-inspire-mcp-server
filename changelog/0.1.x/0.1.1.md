# 0.1.1 — 2026-10-01

## Added

- **`cern_inspire_search_literature`** — one page of INSPIRE-HEP papers for INSPIRE query syntax or free text, filtered by `document_types`, `subjects`, and `year_from`/`year_to`, sorted by relevance, recency, or citations; `page × size` stays within INSPIRE's 10,000-result window.
- **`cern_inspire_get_paper`** — one paper's full record by recid, arXiv ID, or DOI: authors with affiliations (capped by `max_authors`, 0–500), abstract, identifiers, citation counts, linked experiments, texkeys, `citingQuery`/`referencesQuery`, and a `hepdata` block reporting whether HEPData holds the paper's tables.
- **`cern_inspire_export_citations`** — INSPIRE's verbatim BibTeX or LaTeX `\bibitem` entries (`latex-eu`, `latex-us`) for the papers a literature query selects, up to 50 per call.
- **`cern_inspire_search_authors`** — physicist profiles by name, BAI, ORCID, INSPIRE ID, or author recid, with positions, advisors, arXiv categories, and a `literatureQuery` for the person's papers.
- **`cern_inspire_get_citation_summary`** — h-index, citation totals, average citations, and paper counts per citation bucket for one author or any literature query, narrowed by document type, subject, and year; `exclude_self_citations` recounts without self-citations.
- **`cern_inspire_search_experiments`** — experiments, collaborations, and facilities by name, accelerator, INSPIRE legacy name, or recid, with institutions, lifecycle dates, paper count, and a `literatureQuery`.
- **`cern_inspire_search_hepdata`** — HEPData measurement records through INSPIRE's `data` index, each with its paper recids, keywords, record DOI, latest version, table count, and hepdata.net URL; table values are not read.
- **`cern_inspire_list_reference`** — static tables for INSPIRE search syntax, identifier forms, `document_types` and `subjects` values, citation buckets, and HEPData versions and DOIs; no upstream call.
- **`inspire://literature/{recid}`** — the `cern_inspire_get_paper` dossier as JSON, with the first 25 authors.
- **INSPIRE request boundary** — one process-wide pacer at 12 requests per 5 s (INSPIRE allows 15) and 4 in flight, 2 retries, a 55 s budget per tool call, an 8 MiB response ceiling, and a `User-Agent` naming the server; nothing is sent to hepdata.net.
- **Configuration** — no API key and no server-specific environment variables; `.env.example` and the Docker image set `MCP_SESSION_MODE=stateless`, and the pacer is per process, so run one replica per egress IP.
- **Data terms** — INSPIRE metadata is mostly CC0 under INSPIRE's terms of use, and HEPData records are CC0, cited by record DOI; author email addresses are never requested.
