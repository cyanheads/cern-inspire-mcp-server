# 0.1.3 — 2026-10-16

## Added

- **Author paging** — `cern_inspire_get_paper` accepts zero-based `author_offset` and returns `authorOffset` plus `nextAuthorOffset` after a nonempty page when normalized authors remain; affiliations and identifiers survive each page. The literature resource retains the first 25 authors. ([#17](https://github.com/cyanheads/cern-inspire-mcp-server/issues/17))
- **Citation export filters** — `document_types`, `subjects`, `year_from`, and `year_to` apply to every citation page and match-count request; `appliedFilters` echoes the selection on both response surfaces. ([#18](https://github.com/cyanheads/cern-inspire-mcp-server/issues/18))

## Changed

- **Author budgets** — nonnegative integer `max_authors` values above 500 succeed with an effective cap of 500 and a requested/effective-budget notice, combined with paging and record notices. ([#16](https://github.com/cyanheads/cern-inspire-mcp-server/issues/16))
- **Development tooling** — synchronize framework skills, maintenance checks, Bun 1.4.3 images, Docker dependency pruning, and CodeQL language categories.

## Fixed

- **Empty field clauses** — literature search, citation summary, and citation export reject recognized empty clauses such as `a:` as `invalid_query` before upstream I/O, preserving quoted, regex, nested-selector, and negated values; this is not complete grammar validation. ([#15](https://github.com/cyanheads/cern-inspire-mcp-server/issues/15))
- **Registry launch metadata** — npm entries use `npx` and the package bin; the HTTP entry explicitly selects the HTTP transport.
