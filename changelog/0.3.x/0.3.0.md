# 0.3.0 — 2026-11-15

## Added

- Added `cern_inspire_search_institutions`: find INSPIRE institution records by name words, by one exact recorded name (`legacy_ICN:"NAME"`), or by recid, with the hierarchy, location, parent and successor links, paper count, and the `affid:N` query that selects their papers ([#27](https://github.com/cyanheads/cern-inspire-mcp-server/issues/27)).
- **`page`:** `cern_inspire_search_authors` and `cern_inspire_search_experiments` page within INSPIRE's 10,000-result window, with `page`, `hasMore`, and `nextPage`; a page past the last, or `page × limit` over 10,000 (`beyond_result_window`), is reported ([#26](https://github.com/cyanheads/cern-inspire-mcp-server/issues/26)).
- **Paper dossiers:** `cern_inspire_get_paper` and the literature resource return `supervisors` (every thesis supervisor, not paged), `thesis` (degree type, granting institutions with recids, defense date, date), and `publications[]` `cnum`, `conferenceRecid`, and `parentRecid` ([#28](https://github.com/cyanheads/cern-inspire-mcp-server/issues/28)).

## Changed

- **`publications[]`:** an entry that holds only conference or parent links is now listed in record order, which can shift an existing entry's index ([#28](https://github.com/cyanheads/cern-inspire-mcp-server/issues/28)).
- **Next-page notices:** every paged tool names the page size to repeat (`request page 2 with limit 25` or `with size 10`), since a replay without it repeated or skipped rows.
- **Author and experiment searches:** the `upstream_unreadable` recovery retries the same page and limit; the author window recovery leads with a BAI, ORCID, or INSPIRE ID, since extra name parts widen a name search; a digits-only experiment query that matches nothing names the recid ([#26](https://github.com/cyanheads/cern-inspire-mcp-server/issues/26)).
- **`cern_inspire_list_reference`:** says `refersto:` and `citedby:` take recids, documents `publication_info.cnum:CNUM` and the institution lookup, and states the `affid:N` single-record match.
- **Error responses (framework):** the closing `content[]` term gains `retry after N` on rate-limit errors, and `error.data` no longer carries the upstream body for unexpected statuses.
- **cern-inspire-guide:** skill 1.0 → 1.1, covering institution lookup, paging, thesis details, and arXiv version handling.
- **Dependencies:** `@cyanheads/mcp-ts-core` ^0.13.18 → ^0.13.22, `@biomejs/biome` 2.6.3 → 2.6.7, `@types/node` 26.6.5 → 26.6.6, `@vitest/coverage-istanbul` 5.0.5 → 5.1.0, `vitest` ^5.0.5 → ^5.1.0, `tsc-alias` ^1.9.9 → ^1.9.10; `engines.bun` >=1.4.0 → >=1.4.4.
- **Development tooling:** sync framework skills, scripts, changelog template, and `.env.example` (`MCP_JWT_EXPECTED_AUDIENCE`, `MCP_JWT_EXPECTED_ISSUER`).

## Fixed

- **arXiv version suffixes:** `cern_inspire_search_literature`, `cern_inspire_export_citations`, and `cern_inspire_get_citation_summary` drop a `vN` suffix from an arXiv ID in the query and name each rewrite in a notice; `cern_inspire_get_paper` accepts an upper-case `V2` ([#25](https://github.com/cyanheads/cern-inspire-mcp-server/issues/25)).
- **Empty HEPData clauses:** `cern_inspire_search_hepdata` rejects `a:`, `a:""`, and `a: not`, alone or beside other terms, as `invalid_query` instead of widening the match ([#29](https://github.com/cyanheads/cern-inspire-mcp-server/issues/29)).
- **`averageCitations`:** `cern_inspire_get_citation_summary` text shows the unrounded value `structuredContent` carries.
