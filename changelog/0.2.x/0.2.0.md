# 0.2.0 — 2026-10-26

## Added

- **cern-inspire-guide:** Add the cern-inspire-guide skill, available as an MCP resource and in published packages.
- **Paper dossiers:** Return recorded contributor roles and public attached-document links, including supplied filename, description, material and full-text flags, through `cern_inspire_get_paper` and the literature resource ([#20](https://github.com/cyanheads/cern-inspire-mcp-server/issues/20), [#21](https://github.com/cyanheads/cern-inspire-mcp-server/issues/21)).
- **Agent Plugins:** Publish root `plugin.json` and `mcp.json` alongside client overlays.

## Changed

- **Selection verification:** Filtered and later-page literature searches and citation exports verify their selection. A citation export page that previously succeeded after its count request failed now fails the call; retry after the reported upstream failure clears ([#23](https://github.com/cyanheads/cern-inspire-mcp-server/issues/23)).
- **Result budgets:** Accept oversized positive integer budgets and disclose the effective ceiling across literature, HEPData, citation export, author and experiment searches ([#22](https://github.com/cyanheads/cern-inspire-mcp-server/issues/22)).
- **Development tooling:** Sync framework skills, packaging checks and audit classification; use Bun 1.4.3 → 1.4.4 and a one-day dependency release-age floor.

## Fixed

- **Empty query clauses:** Reject empty and whitespace-only quoted field values before upstream requests in literature search, citation summary and export ([#15](https://github.com/cyanheads/cern-inspire-mcp-server/issues/15)).
- **Selection fallback:** Suppress excluded papers and exhausted-page repeats caused by INSPIRE reference fallback ([#23](https://github.com/cyanheads/cern-inspire-mcp-server/issues/23)).
- **Rendering:** Preserve error text for one Markdown escape at the framework boundary and align rendering with the adopted framework.
- **MCPB packaging:** Remove build-only files while preserving SDK skill runtime modules in cleaned bundles ([mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794)).
